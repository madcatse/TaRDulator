User guide · version 0.10.1

TaRDulator

Turn TAP and TZX tapes into a TR-DOS disk with your own selection menu. Prepare a collection in Windows, then run it on a Spectrum with a disk interface.

Your first collection

Extract the whole application folder and run TaRDulator.exe. You need Windows 10/11 x64 and .NET Framework 4.8. You do not need to install Python, SkoolKit or Z80to separately. Keep the engine, help and licenses folders beside the EXE.

  1. Click + TAP / TZX and select one or more tape files, or drag files into the window.
  2. Edit menu titles in the table if needed. Use ↑ / ↓ to change the order. Remove removes the selected row from the collection; it does not delete the tape file.
  3. Leave Model: Auto and Disk conversion: Auto (Z80to) selected. Leave Start blank.
  4. On the right, choose menu elements and adjust their positions and colours. You can also load a background image.
  5. Click Calculate size to check tape loading and disk capacity. Then click Create TRD and choose an output file.
  6. Open the TRD in a TR-DOS emulator and check each game. See Build and run a TRD.

Conversion is local. This guide and bundled licence texts work offline; only external project links need an internet connection. If Windows asks which application should open the HTML file, select a web browser.

Window and options

The left column contains tapes, settings for the selected program and the log. The right column contains options beside the logo, a menu preview and editor tabs. Build controls, progress and help are at the bottom.

Interface language

Select Русский or English to the left of the logo. Labels, the logo and the help language change together. Your preference is saved in settings.json beside the EXE. Game names, disk menu text and custom layouts are not translated.

Disk startup

  • Collection menu starts with a game selection menu.
  • One program without a menu requires exactly one tape in the list. The disk starts its loader directly. The menu editor is temporarily disabled; switching back restores access to your existing layout.

Direct startup still uses a boot.B loader and data files. It does not pack the entire program into a single B file.

Bottom buttons

  • Create TRD loads tapes, packs programs and writes the disk image.
  • Calculate size loads and packs programs without writing a TRD. Creating a disk repeats the calculation.
  • Cancel stops the current operation.
  • Open TRD folder opens File Explorer with the last created image selected. It becomes available after a successful build.
  • Help or F1 opens this guide in your browser. Help remains available during conversion.

48K / 128K loading

Settings beneath the table apply to the selected row. The tape loading model and disk conversion mode are separate choices.

SettingBehaviour
Model: AutoTries 128K loading and checks changes to extra RAM banks. Also observes paging, screen switching and AY activity during the first 100 frames after loading. If there is no 128K evidence, or 128K loading fails, it checks 48K. The log explains the decision.
Model: 48K / 128KLoads the tape using your chosen model. Use this when you know the requirements of the particular game version.
Auto (Z80to)Uses standard Z80to packing. Retains 128K when extra banks or 128K/AY activity have been detected.
Preserve 128KPrevents reduction of a 128K snapshot. Does not add extra banks to a program loaded in 48K mode.
Force 48KDiscards extra 128K banks. Use only for a program that does not need them; a real 128K game may stop working.
StartNormally blank. For advanced use, specify an address at which to stop tape loading, such as 43849 or 0xAB49. If that address is not reached, conversion fails.

Each loading attempt has a limit of 20 minutes of Spectrum time. Emulation is accelerated, so this is not necessarily 20 minutes of real waiting. Auto detection checks loading and initial execution, not every level of the game.

Loading strategies for complex tapes

Version 0.10.1 uses verified settings for specific dumps: Fearzone 2018 separates keyboard polling from ROM loading; Dizzy 7 NEW and Yazzie 128 are captured after unpacking or initialization. New View loads all five parts from disk, and MILKY2 loads both parts. They share a chain loader that preserves the original CODE blocks and launch order.

The log and .report.json identify the strategy and its reason. Profiles match the complete SHA-256 hash; a different release may have a different loader. See LOADING_STRATEGIES.md (Russian) for the mechanism catalogue and support workflow.

The supplied Castlevania EN/RU and Dizzy 8 dumps are currently unsupported: transferring their remaining blocks after startup has not been verified. The program explains the failure and does not create an incomplete image. This applies to these specific dumps, not all editions of each game.

Sizes in the table

File is the TAP/TZX size; RAM is snapshot memory before packing; Disk is the space used by that program's files, including its loader and sector rounding. Values are in KiB (1024 bytes). The final total also includes the disk menu. Changing a program's settings clears its previous size result.

Menu editor

Each page holds up to 16 games. Pages are added automatically. Selecting a game in the tape table opens its page; use the list above the preview to choose a page manually.

Layout

Select the heading, hint, navigation label, page indicator or game item in the element list, or click its text in the preview. Drag it, or enter X, Y and width in character cells. The display has 32 columns and 24 rows; coordinates start at zero.

You can change text, visibility, text colour, paper colour and brightness. The heading is optional. 1 column / 2 columns arranges the current page's game items; Grid helps align them. Resolve overlaps or out-of-bounds items using the editor's warning.

Game names allow up to 29 characters; other labels allow up to 32. Latin and Russian letters, digits and ordinary punctuation are supported. Russian text displays on the Spectrum without a modified Russian ROM.

Navigation labels have their own positions and styling. Use {page} and {pages} in their text for the current page and page count. Navigation appears when there are at least two pages. Editing the hint does not remap the game selection keys.

Background / SCR

Load a SCR file (256×192, exactly 6912 bytes), or a PNG, JPEG or BMP. Ordinary images are converted to Spectrum graphics with colours assigned per 8×8 cell; optional dithering is available. All pages share one background. Text labels cover their background area with the selected paper colour.

Background → SCR exports only the background; Menu → SCR exports the selected page with its text. Reset background restores the built-in image.

Templates

Save template writes a .t2menu file containing the shared background, heading and all page layouts. Open template restores them. Tape files and game names are not stored in a template. Positions belong to a page and item slot, rather than to a particular game name.

Layouts are not saved automatically when you close the application. If removing games reduces the page count, unused page layouts are retained for reuse during the session and in saved templates.

Build and run a TRD

A TRD image is 640 KiB, with 636 KiB available for files and 128 directory entries. There is no 16-game limit for the whole disk: capacity depends on program sizes, file counts and menu files.

A successful build writes a .report.json beside the TRD with loading results, machine choices, sizes and packing logs. Source tapes remain unchanged. An existing image is replaced only after confirmation in the save dialog and successful preparation of the new disk.

  1. Open the TRD in an emulator with Beta Disk/TR-DOS. The tested setup is Pentagon 128K, for example in Fuse.
  2. If the disk does not start automatically, enter RUN "boot" in TR-DOS. For direct startup, RUN also works.
  3. Select games with 1–9, then A–G. N selects the next page and P the previous page; navigation wraps around.

From ordinary 48K BASIC with TR-DOS available, use:

RANDOMIZE USR 15619: REM: RUN "boot"

To return from a game to the menu, reset the emulator and load the disk again. There is no universal exit key for running games.

Special TAP/TZX: profile catalog

For individually verified versions, the converter automatically selects special handling or a compatibility patch. It matches the full SHA-256 of the entire file, not the game name. Renaming a file makes no difference; changing even one byte produces a different hash and does not enable another dump’s patch. Unknown files use the generic converter.

Leave Model and Transfer on Auto and Start empty. The SHA-256 and matched profile are shown in the log during measurement/building and saved in the report beside the TRD. TAP block XOR checksums are checked separately: they detect corruption but do not identify a game version.

This catalog does not guarantee a complete playthrough on every Spectrum clone. “Delta hardware test pending” marks Escape fixes tested in software without a floating bus. Unsupported dumps are explicitly rejected.

Troubleshooting

SituationWhat to check
Not checkedThe tape has been added but not loaded yet. Calculate its size or build a disk.
Ready / CheckReady means loading and packing succeeded. Check points to a log explanation, such as a snapshot in ROM/BASIC or reduction to 48K. Test the disk in either case.
Timeout or remaining blocksThe loader may require input, use protection or load later parts. Check the original tape in an emulator and confirm the required machine model. Arbitrary level loading and tape saving are not automatically adapted.
Disk fullRemove some games. Both free bytes and directory entries matter, including menu files.
Menu cannot be builtRead the warning below the preview. Fix overlapping, oversized or out-of-bounds labels. Direct startup requires exactly one tape.
Converter or help missingExtract the whole archive. Do not separate the EXE from its folders. You can open the HTML guide manually from help.

Not every TZX feature is supported: unsupported commands and incomplete loads are rejected with an explanation. Special profiles for WEC Le Mans (128K branch) and MILKY2 (both parts loaded from disk) apply only to verified file hashes, not filenames. For these, use Auto model and conversion and leave Start blank.

Snapshot restoration uses a Z80to loader which can change a few bytes below the stack. Compatibility with every game and machine is not guaranteed. Results for specific tested tapes are in VALIDATION.md (Russian).

Fonts and ROMs

Sinclair Spectrum ROMs are supplied in SkoolKit resources; the menu's Latin font comes from the ROM. ROM rights notices were taken from the Fuse distribution.

The Russian font was extracted from the user-supplied win91_optimized.tap (Windows’91). The tape does not identify a font author or licence; rights remain with their respective owners. 62 glyphs were copied unchanged; Ё/ё and Ъ/ъ were derived from the same set.

Local tests used Pentagon/TR-DOS ROMs from ZX-Spectrum_MISTer; these are not included in the portable application folder. Provenance and hashes are recorded in THIRD_PARTY.md (Russian).

The release's source folder contains application source and a SkoolKit source archive. User TAP/TZX files and games are not included. Third-party component terms are provided in their licences.
