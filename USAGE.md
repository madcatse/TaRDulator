# Руководство ТаРДулятора

[Главная страница](README.md) · [English help](help/index.en.html)

## Запуск

В готовой папке приложения откройте `TaRDulator.exe`
(в проекте: `dist/TaRDulator/TaRDulator.exe`). Установка Python и .NET SDK не нужна.
Нужна Windows 10/11 x64 с .NET Framework 4.8. Переносите всю папку `TaRDulator`,
включая `engine`, а не один EXE. Программа работает локально, без сети.

1. Добавьте TAP или TZX кнопкой или перетаскиванием файлов в окно.
2. При желании измените порядок и подписи. Параметры выбранной программы находятся под таблицей.
3. Выберите фон. Есть встроенный фон, импорт SCR и конвертация PNG/JPEG/BMP.
4. В редакторе меню выберите страницу над предпросмотром, затем надпись или пункт
   игры. Перетащите его мышью либо задайте координаты, ширину и цвета.
   Названия игр, заголовок, подсказка и надписи переходов поддерживают русский язык.
5. Нажмите **Рассчитать размер**, чтобы узнать занятую ёмкость без записи диска.
   Затем нажмите **Создать TRD** и выберите файл назначения.
6. Откройте TRD в эмуляторе с Beta Disk/TR-DOS. Для проверенного режима используйте
   Pentagon 128K. Если меню не появилось автоматически, выполните `RUN "boot"`
   из TR-DOS. В обычном 48K BASIC: `RANDOMIZE USR 15619: REM: RUN "boot"`.
7. На каждой странице до 16 программ: выбор клавишами `1`–`9`, затем `A`–`G`.
   `N` открывает следующую страницу, `P` — предыдущую; переходы идут по кругу.
   Принимаются и строчные буквы. Для возврата из игры в меню используйте сброс
   и повторную загрузку диска; общей клавиши выхода из игры нет.

Примеры сборников в `output/` создаются при локальной проверке на собственных TAP.
Они не входят в репозиторий и переносимую сборку.

Файл `.report.json` рядом с TRD содержит исходные хеши, параметры снимков,
журнал загрузки и упаковки, размеры TAP/RAM/файлов на диске, выбранный режим
переноса, модель результата, число страниц и файлов, макеты страниц и хеш образа.

## Размеры и перенос 48К/128К

- **Файл** — размер исходного TAP/TZX; **RAM** — объём памяти снимка до упаковки
  (для 128К учитываются все восемь банков); **Диск** — суммарное место файлов
  конкретной игры вместе с загрузчиком и округлением до секторов по 256 байт.
  Все значения в КиБ (1024 байта). Общий итог дополнительно включает меню,
  показывает число страниц и занятых записей каталога из 128.
- **Рассчитать размер** действительно загружает и упаковывает TAP, поэтому
  требует примерно столько же времени, сколько сборка. Готовый TRD и отчёт
  не записываются. При сборке данные рассчитываются заново, без кеша.
  Изменение параметров игры сбрасывает её старые размеры.
- **Модель → Авто** выбрана по умолчанию. Сначала кассета загружается в 128К.
  Дополнительные банки сравниваются с памятью после запуска ROM, до первого
  кассетного блока. Если загрузчик изменяет их, сохраняется 128К. Если изменений
  нет, дополнительно наблюдаются первые 100 кадров: переключение RAM/экрана или
  запись музыкальных регистров AY сохраняют 128К. Если признаков нет или загрузка
  128К не удалась, проверяется 48К. Выбирается успешно загруженный
  вариант; причина и обе попытки сохраняются в отчёте. При отсутствии данных для
  проверки банков успешный 128К-снимок сохраняется консервативно.
  Название файла и слова «48K/128K» не используются для определения модели.
  Это ограниченная проверка загрузки и начала работы, не доказательство совместимости всех уровней игры.
  Ручные **48К** и **128К** сохраняются; режим переноса на диск задаётся отдельно.
- Лимит одной попытки увеличен с 300 до **1200 секунд времени Spectrum**
  (20 минут); эмуляция ускорена, поэтому ожидание на ПК обычно гораздо короче.
- **Авто (Z80to)** использует штатную обработку Z80to 1.4: сжатие, обработку
  пустых банков и его проверку возможности переноса 128К-снимка в 48К.
  Если загрузчик менял дополнительные банки или обнаружена работа с 128К/AY, включается сохранение 128К,
  чтобы упаковщик не отбросил обнаруженные данные.
- **Сохранить 128К** запрещает автоматическое сокращение 128К-снимка.
  Если кассета загружена в модели 48К, дополнительных банков этот режим не создаёт.
- **Принудительно 48К** удаляет дополнительные банки 128К и отключает переключение
  памяти. Используйте его для программы, которой достаточно 48К.
  Настоящая 128К-игра может перестать работать; в интерфейсе появляется пояснение.
- Под таблицей показана модель результата, сообщённая упаковщиком. Процент
  уменьшения сравнивает место на диске с исходной RAM; при переносе 128→48 он
  включает и отброшенные банки, поэтому это не чистый коэффициент сжатия.

Сам алгоритм сжатия Z80to не менялся. Новый формат хранения только
отличий от памяти после включения пока не реализован. Нулевые области и буфер
принтера не вырезаются по предположению, что они не нужны программе.

## Возможности и ограничения

- Один стандартный TRD размером 640 КиБ; для файлов доступно 636 КиБ.
  Общего ограничения в 16 программ больше нет: число игр определяется свободным
  местом и каталогом на 128 файлов. Загрузчики и экраны меню также учитываются.
  Каждая страница занимает 6912 байт и одну запись каталога; общий BASIC-загрузчик
  меню занимает ещё один файл. Число файлов каждой игры зависит от упаковки.
  Например, если все игры занимают по три файла, в каталог поместится 41 игра
  и меню из трёх страниц; свободного места при этом тоже должно быть достаточно.
- У каждой программы независимые имена файлов на диске, в том числе при одинаковых
  исходных именах. Исходные TAP не изменяются.
- Проверяются структура TAP, контрольные суммы, соответствие заголовков данным,
  границы и поддерживаемые команды TZX,
  геометрия TRD и переполнение диска. При ошибке сборка прекращается целиком.
  Уже существующий TRD заменяется только после успешной подготовки всего образа.
- Названия игр — до 29 символов, заголовок и подсказка — до 32. Поддерживаются
  печатные ASCII-символы и весь русский алфавит, включая Ё/ё и строчные буквы.
  Русский шрифт работает **в пунктах меню на Spectrum**, без русифицированной ROM.
  Русские буквы взяты из предоставленного `win91_optimized.tap` (шрифт Windows'91).
  62 исходных глифа перенесены без изменений; отсутствующие Ё/ё и Ъ/ъ добавлены
  на основе Е/е и Ь/ь из того же набора. Латиница использует шрифт Spectrum ROM.
  Надписи заранее рисуются в SCR; загрузчик только показывает экран и принимает
  клавишу. Предпросмотр Windows и конвертер используют одинаковые растры букв.
- Фон — обычный Spectrum SCR: 256×192, 6912 байт. Изображение кадрируется по центру
  до 4:3; для каждой ячейки 8×8 подбираются INK/PAPER и общая яркость. Можно включить
  упорядоченный дизеринг. Экспортируются отдельно фон или выбранная страница
  готового меню с надписями. Фон общий для всех страниц.
  Каждая надпись закрывает участок фона плашкой выбранного цвета.
- TAP/TZX сначала загружается в модели Spectrum средствами SkoolKit, затем снимок
  переносится на диск через Z80to. Первая версия **не переписывает кассетные
  обращения внутри игры**. Подгрузка уровней, сохранение на кассету, запросы
  ввода во время загрузки и произвольные защиты могут не поддерживаться.
- TZX: поддерживаются обычные и турбоблоки, данные, тоны, импульсы, паузы,
  простые циклы и информационные блоки. Неподдерживаемые команды (например,
  переходы, вызовы последовательностей, меню выбора и вложенные циклы)
  отклоняются явно. Используется загрузчик [SkoolKit 10.1](https://skoolkit.readthedocs.io/en/stable/commands.html#tap2sna-py).
  Если остановка TZX оставляет блоки данных, перенос отклоняется даже при
  сообщении эмулятора «Tape finished». Условная остановка 48К при автовыборе
  допускает полную загрузку в 128К. Исключение — проверенный профиль WEC
  Le Mans из `games48-128.zip`: распознаётся полный SHA-256 файла, корректно
  эмулируется чтение AY при определении модели, загружается ветка 128К
  до блока 35. Перед упаковкой побайтно проверяются 38 020 байт основного
  кода и 12 288 байт банков 4/6. Блоки 37/39 принадлежат подгрузке 48К
  и в ветке 128К не используются. Это не общий обход остановок TZX.
  Для этого WEC выбирайте **Авто** или **128К**, перенос **Авто** или
  **Сохранить 128К**, поле «Старт» пустое. Версия 48К и принудительное
  сокращение до 48К явно отклоняются как неподдерживаемые.
- Поле «Старт» обычно пустое. При необходимости задайте адрес, на котором нужно
  остановить загрузку (`43849` или `0xAB49`). Если адрес не достигнут после
  полной загрузки, программа сообщает об ошибке.
- «Готово» означает успешную загрузку и упаковку, а не прохождение игры.
  «Проверить» отсылает к пояснению в журнале и подсказке ячейки: снимок в ROM/BASIC
  либо принудительное сокращение 128К до 48К. Снимок в ROM допустим, например
  для BASIC-программ, но требует проверки продолжения выполнения.
- Снимки восстанавливаются небольшим кодом загрузчика. Как и у Z80to, возможны
  изменения нескольких байтов под стеком. Точная совместимость всех TAP,
  моделей компьютеров и версий TR-DOS не гарантируется.

## Редактор меню

- Список над предпросмотром выбирает страницу и показывает номера её игр.
  При выборе игры в таблице редактор переходит на соответствующую страницу.
  Страницы создаются автоматически по мере добавления TAP, по 16 пунктов.
  Новая страница получает копию расположения элементов первой страницы;
  затем её можно настраивать независимо.
- Нажмите на заголовок, пункт игры, подсказку или надпись перехода в предпросмотре либо выберите
  элемент из списка под экраном. Поле текста редактирует выбранную надпись;
  название игры синхронизируется с таблицей TAP. Текст заголовка общий,
  его положение, оформление и видимость задаются отдельно на каждой странице.
- Перетаскивайте надписи мышью или задайте **X**, **Y** и **Ширину**. Координаты
  начинаются с нуля: X = 0–31, Y = 0–23; одна ячейка — 8×8 пикселей.
  Все 24 строки экрана доступны. Ширина пункта включает клавишу и два пробела.
  Длинный текст обрезается по ширине; исходное название в таблице сохраняется.
- **Показывать** отключает заголовок, подсказку, надписи переходов или номер страницы.
  Пункты выбора игры всегда видимы.
  Текст подсказки произвольный; по умолчанию — «НАЖМИТЕ КЛАВИШУ ИГРЫ».
  Для выбора нужна соответствующая клавиша `1`–`9` / `A`–`G`, а не любая клавиша.
- **Назад (P)**, **Далее (N)** и **Номер страницы** настраиваются как отдельные
  строки: текст, координаты, ширина, цвета и видимость. В их тексте `{page}`
  заменяется текущим номером страницы, `{pages}` — общим количеством.
  Например, `{page} из {pages}` отображается как «2 из 3».
  Клавиши переходов остаются `P` и `N` независимо от текста надписей.
  При единственной странице все три строки автоматически скрыты.
- **1 колонка** / **2 колонки** расставляют пункты автоматически. Можно затем
  переместить каждую строку отдельно. Расстановка и **Сбросить макет страницы**
  применяются только к выбранной странице. Сетка и рамка выделения видны только в редакторе.
- Текст, фон плашки и яркость настраиваются для каждой надписи. Пересечения,
  выход за экран и одинаковые цвета текста/фона блокируют сборку с объяснением.
- На вкладке **Макеты** сохраняйте и открывайте `.t2menu`. В файле находятся фон,
  общий заголовок и оформление всех страниц, включая надписи переходов
  и позиции 16 возможных пунктов на каждой странице. TAP и названия игр
  в макет не входят. Позиции привязаны к странице и номеру пункта;
  изменение порядка игр сохраняет расположение строк.
  Если после удаления игр страниц стало меньше, их настройки сохраняются
  для повторного использования и входят в файл макета.
  Старые макеты версии 1 открываются; при добавлении страниц их расположение
  копируется с первой. Если новые подписи пересекаются с прежними элементами,
  редактор предложит их переместить или скрыть.
  При закрытии приложения макет автоматически не сохраняется — используйте
  кнопку сохранения. Новые макеты записываются в формате версии 2.

## Сборка из исходников

GUI написан на C# / Windows Forms; конвертер — на Python. Сборка GUI использует
компилятор .NET Framework, конвертер упаковывается PyInstaller в автономную папку.

Требования для разработчика: Windows x64, Python 3.12 x64 с pip, .NET Framework 4.8.

```powershell
.\setup.ps1 -Python 'C:\Path\To\python.exe'
.\build.ps1 -Python 'C:\Path\To\python.exe'
```

Зависимости устанавливаются в `.tools` внутри проекта. Setup скачивает SkoolKit,
PyInstaller и Z80to 1.4, проверяя SHA-256 архива Z80to. Полный набор версий —
`requirements-build.txt`. При повторной сборке закройте запущенный ТаРДулятор.

Проверки ядра:

```powershell
$env:PYTHONPATH = "$PWD\.tools\python-packages"
New-Item -ItemType Directory -Force .work | Out-Null
python -m unittest discover -s tests -v
```

Конвертер также принимает JSON на стандартном вводе и выдаёт NDJSON-события:

```json
{"action":"build","output":"C:/Output/games.trd","title":"MY GAMES","games":[{"path":"C:/Games/game.tzx","title":"GAME","machine":"auto","start":"","transfer_mode":"auto"}]}
```

Замену существующего файла разрешает `"overwrite":true`. Не передавайте это поле,
если замена не нужна. Для анализа используется `{"action":"analyze","paths":["..."]}`.
Для расчёта без записи задайте `"action":"measure"` с теми же параметрами меню
и игр; `output` не нужен и игнорируется. `transfer_mode` принимает `auto`
(по умолчанию), `preserve` или `48`. Модель загрузки задаётся независимо в `machine`.

Для независимого оформления страниц передайте `pages` — массив макетов, по одному
на каждые 16 игр. В `items` каждого макета должно быть столько элементов, сколько
игр на его странице. Помимо `title` и `hint`, макет содержит `previous`, `next`
и `page` с теми же свойствами оформления и полем `text`. При отсутствии `pages`
применяются стандартные макеты; прежнее поле `layout` также принимается
и повторяется на страницах. Файлы `.t2menu` хранят по 16 позиций для дальнейшего
редактирования, а запрос сборки передаёт только используемые пункты.

Основные файлы: `src/engine.py` — TAP, TRD и загрузчик меню; `src/App.cs` и
`src/MenuEditor.cs` — GUI; `src/GameOptions.cs` — параметры игр и размеры;
`src/MenuLayout.cs` — макеты; `src/SpectrumScreen.cs`
и `src/menu_screen.py` — совпадающая отрисовка SCR. `assets/win91-font.bin` содержит
исходный блок русского шрифта; `assets/win91-font.json` — его происхождение и хеши.
`scripts/extract_win91_font.py` повторяет извлечение из пользовательского TAP,
а `scripts/make_font.py` преобразует раскладку КОИ-7 и объединяет глифы со шрифтом ROM.
Тесты в `tests` проверяют форматы, границы диска, сохранность файлов, макеты,
кириллицу и побайтное совпадение C#/Python.

## Отладка

Для дополнительных локальных проверок можно установить portable Fuse 1.6.0 в `.tools/fuse`.
Он не нужен для работы приложения и не включается в переносимую папку `dist`.
Эмулятор и тестовые ROM в репозиторий не включены. Скрипт `OpenExample.cmd`
работает только после подготовки собственного `output/FirstCollection.trd`.
Результаты проверки конкретных программ описаны в `VALIDATION.md`.

Сторонние компоненты и их лицензии перечислены в `THIRD_PARTY.md`.

## English quick start

Open `TaRDulator.exe` and select **English** beside the logo.
Add TAP/TZX files, edit disk menu text and positions, then choose **Create TRD**.
Keep the whole application folder together. The language preference is saved
beside the executable; changing it does not translate your disk menu content.
WEC Le Mans from the supplied archive supports the verified 128K branch. Use
Auto model and Auto conversion; leave Start blank. Its 48K tape overlay branch
is not supported. Test generated disks on the target hardware; emulator success alone does not confirm Delta compatibility.
