# ТаРДулятор / TaRDulator 0.11.0

Игры теперь удобнее переносить между сборниками TR-DOS: вместо повторяющихся
`G00`, `G01` каждая программа получает стабильный код и общий префикс файлов.

- Например: `7K3Q9AZ` — BASIC-загрузчик, `7K3Q9AZ0`, `7K3Q9AZM` — блоки CODE.
- Имена зависят от кассеты, параметров конвертации и результата упаковки.
  Переименование TAP, изменение подписи или порядка игр их не меняют.
- Ссылки в загрузчиках и меню обновляются автоматически. Совпадения имён и
  повторные игры внутри сборника получают свободные коды.
- Префикс виден в журнале; полный список файлов каждой игры есть в `.report.json`.
- На дисках без меню сохранён отдельный переносимый загрузчик, а `boot`
  содержит его копию для прямого запуска.

**Как переносить:** скопируйте весь комплект игры с её BASIC-загрузчиком,
сохранив имена. Запускайте через `RUN "код"` или добавьте пункт в меню
принимающего диска. Общие `boot` и `MENU*` исходного сборника переносить не нужно.
Импорт готовых TRD в редактор меню пока не предусмотрен.

Старые диски нужно пересобрать из TAP/TZX. Сокращённый хеш не гарантирует
абсолютную уникальность между независимыми дисками; при совпадении сравните
полные `file_id` в отчётах. Разные комплекты с совпавшими именами пересоберите
вместе, чтобы утилита разрешила конфликт. Самостоятельное переименование
записей каталога без изменения загрузчиков не поддерживается.

**Установка:** скачайте `TaRDulator-v0.11.0-win-x64.zip`, распакуйте папку целиком
и запустите `TaRDulator.exe`. Нужны Windows 10/11 x64 и .NET Framework 4.8.
Python, справка, исходники и лицензии включены; игры в комплект не входят.
Контрольная сумма архива находится в `SHA256SUMS.txt`.

## English

Games now use stable TR-DOS filenames instead of collection-position names
such as `G00` and `G01`. A seven-character identifier groups the BASIC loader
and its CODE parts, for example `7K3Q9AZ`, `7K3Q9AZ0` and `7K3Q9AZM`.

- Names include tape content, conversion settings and packed output, and remain
  stable when renaming a source file, changing menu labels or reordering games.
- Generated BASIC references and menus are updated together with filenames.
  Repeated games and short-hash collisions within a collection receive free names.
- The log shows each prefix; `.report.json` lists the complete game bundle.
- Direct-launch disks retain a portable named loader alongside its `boot` copy.

Copy the entire game bundle, preserving names, then use `RUN "identifier"`
or update the destination menu. Do not copy the source collection's shared
`boot` and `MENU*` files. Importing existing TRDs into the menu editor is not
supported. Rebuild older images from their original TAP/TZX files.

Short hashes cannot guarantee global uniqueness. If names coincide, compare
the full `file_id` values in the reports; rebuild different conflicting games
together to resolve the conflict. Renaming directory entries alone breaks loaders.

Download `TaRDulator-v0.11.0-win-x64.zip`, extract the complete folder and run
`TaRDulator.exe`. Requires Windows 10/11 x64 and .NET Framework 4.8. Python,
offline help, sources and licenses are included; games are not. Verify the ZIP
against `SHA256SUMS.txt`.
