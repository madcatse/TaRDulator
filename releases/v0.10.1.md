# ТаРДулятор / TaRDulator 0.10.1

Первый официальный выпуск программы для переноса кассет ZX Spectrum TAP/TZX
на диски TR-DOS.

- Сборники с редактируемым многостраничным меню или одна программа без меню.
- Автоматический выбор 48К / 128К, перенос состояния памяти и AY, сжатие данных.
- Собственные фоны, русские и латинские подписи, сохранение макетов.
- Русский и английский интерфейс и автономная справка.
- Профили совместимости для отдельных вариантов кассет, определяемых по SHA-256.

**Установка:** скачайте `TaRDulator-v0.10.1-win-x64.zip`, распакуйте папку целиком
и запустите `TaRDulator.exe`. Нужны Windows 10/11 x64 и .NET Framework 4.8.
Python включён в комплект. Краткая инструкция — в
[README](https://github.com/madcatse/TaRDulator#russian), подробная — по F1.
Игры в комплект не входят.

Архив включает исходники, лицензии и `BUILD_INFO.json`; контрольная сумма
опубликована в `SHA256SUMS.txt`. При переводе предварительного выпуска в
официальный обновлены документация, лицензия и комплект исходников.
Исполняемые файлы и ресурсы работающего приложения сохранены побайтно.

Собственный код: **GPL-3.0-or-later**. Благодарим Richard Dymond и участников
SkoolKit, Tom Dalby за Z80to, а также авторов Python и PyInstaller.
Отдельные условия и происхождение сторонних ресурсов, включая ROM и шрифты:
[THIRD_PARTY.md](https://github.com/madcatse/TaRDulator/blob/main/THIRD_PARTY.md).

Совместимость зависит от кассеты и целевой машины. Особые профили и ограничения
описаны во встроенной справке. Получен положительный отзыв о работе свежей
сборки; модель компьютера в этом сообщении не уточнялась.

## English

The first official release of TaRDulator, a converter from ZX Spectrum TAP/TZX
tapes to TR-DOS disks.

- Collections with an editable multipage menu, or one program without a menu.
- Automatic 48K / 128K selection, memory and AY state transfer, and compression.
- Custom backgrounds, Russian and Latin labels, and reusable layouts.
- Russian and English interface and offline manuals.
- Compatibility profiles for specific tape variants, identified by SHA-256.

**Installation:** download `TaRDulator-v0.10.1-win-x64.zip`, extract the complete
folder, and run `TaRDulator.exe`. Requires Windows 10/11 x64 and .NET Framework 4.8.
Python is bundled. See the
[README](https://github.com/madcatse/TaRDulator#english) for a quick start,
or press F1 for the full manual. No games are included.

The archive includes sources, licenses and `BUILD_INFO.json`; its checksum
is published in `SHA256SUMS.txt`. Promotion from the preview to the official
release updates documentation, licensing and the source bundle.
Application executables and runtime resources remain byte-for-byte unchanged.

Own code: **GPL-3.0-or-later**. Thanks to Richard Dymond and the SkoolKit
contributors, Tom Dalby for Z80to, and the authors of Python and PyInstaller.
Separate terms and the provenance of third-party resources, including ROMs
and fonts, are recorded in
[THIRD_PARTY.md](https://github.com/madcatse/TaRDulator/blob/main/THIRD_PARTY.md).

Compatibility depends on the tape and target machine. Dedicated profiles and
limitations are documented in the offline manual. A user has reported that
the current build works; their message did not specify the computer model.
