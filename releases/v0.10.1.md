# TaRDulator 0.10.1 — private preview

Portable Windows x64 converter from ZX Spectrum TAP/TZX tapes to TR-DOS images.
Includes Russian/English UI, a disk menu editor, single-program mode and
SHA-256 based compatibility profiles.

This version adds targeted patches for Castle Escape, Forest Escape and Pyramid
Escape, and a generated help catalog explaining all recognized special tapes.
The application never identifies these patches by filename alone.

**Delta 128K + AY verification is pending.** The Escape patches pass automated
regression checks with floating bus unavailable. Emulator success is not a
substitute for testing on the physical Delta.

Download the win-x64 ZIP, extract the entire TaRDulator folder, and run
TaRDulator.exe. Keep engine, help, licenses and the other files together.
Python is bundled. The release includes corresponding sources and SHA256SUMS.txt.
No games are included.

This is a private preparatory release. The project's own license and the
Windows'91 font redistribution terms remain unresolved; see LICENSING.md.
